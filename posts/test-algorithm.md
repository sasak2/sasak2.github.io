### 코드 블록

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    printf("%d\n", n * 2);
}
```

### 수식

인라인 수식은 $O(V+E)$ 처럼 쓰고, 별도 줄 수식은 이렇게 써요.

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

달러 기호가 돈일 때는 \$5 와 \$10 처럼 앞에 역슬래시를 붙여요.
