## 글 추가하기

`posts/` 폴더에 `.md` 파일을 하나 올리면 끝이에요. 파일 이름이 글 주소(slug)가 돼요.

```
---
title: 글 제목
date: 2026-10-25
tags: [알고리즘]
summary: 목록에 보일 한 줄 요약
---

여기부터 본문을 마크다운으로 써요.
```

## 태그

메인 페이지의 "확인해보기" 버튼은 아래 태그와 연결돼요.

| 태그 | 주제 |
| --- | --- |
| 전자 | 전자공학, 회로 |
| 해킹 | 보안, CTF |
| 알고리즘 | 문제풀이 |
| 체스 | 체스 |
| 베이스 | 베이스 연주 |
| 메이커 | 제작 활동 |

## 이미지

`posts/img/` 에 이미지를 넣고 `![설명](posts/img/파일.png)` 로 불러와요.

초안으로 두고 싶으면 front matter에 `draft: true` 를 적어요.
