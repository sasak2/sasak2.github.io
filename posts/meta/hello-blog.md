## 글 추가하기

`posts/` 아래 폴더에 `.md` 파일을 하나 올리면 끝이에요. 폴더 경로가 곧 분류가 되고, 파일 이름은 영어나 번호로 써요.

```
posts/hacking/dreamhack/123.md
```

```
---
title: 123번 문제 풀이
date: 2026-10-25
tags: [CTF]
summary: 목록에 보일 한두 줄 요약
---

여기부터 본문을 마크다운으로 써요.
```

## 폴더

각 폴더에 `_folder.json` 을 두면 화면에 보일 한글 이름과 설명, 순서를 정할 수 있어요.

```
{ "title": "드림핵", "description": "워게임 풀이 기록", "order": 1 }
```

최상위 폴더는 메인 페이지 섹션과 연결돼요.

| 폴더 | 메인 섹션 |
| --- | --- |
| electronics | 전자공학 |
| hacking | 해킹 / 보안 |
| algorithm | 알고리즘 |
| maker | 메이커 |
| chess | 체스 |
| bass | 베이스 |

태그는 폴더와 별개로 붙이는 선택 사항이에요.

## 이미지

`posts/img/` 에 이미지를 넣고 `![설명](posts/img/파일.png)` 로 불러와요.

수식은 `$x^2$` 처럼 한 줄 안에, 또는 `$$ ... $$` 로 별도 줄에 LaTeX로 써요.

초안으로 두고 싶으면 front matter에 `draft: true` 를 적어요.
